# お茶会 会費集金

手渡しで受け取った会費・宴会費を、その場でスマホから記録するウェブアプリです。

- 画面は GitHub Pages から配信します。
- 記録は Firebase の Firestore に保存します。
- 入り方は 2 通りです。幹事で共有するパスワードで入るか、幹事の一覧に登録した Google アカウントでサインインします。
- 名簿や金額はこのリポジトリには入っていません。最初の名簿は、会計担当が JSON ファイルから取り込みます。

## 使い方

1. ページを開き、幹事で共有しているパスワードを入れて「入る」を押します。「このスマホで覚えておく」に印を付けると、次からは入力なしで開きます。
2. 最初の 1 回だけ「あなたはどの幹事ですか」と出るので、自分の名前を選びます。記録した人の名前と、受け取った幹事の初期値に使います。あとから右上の「切替」で変えられます。
3. 上のタブで期を選びます。
4. 部員の行をタップし、受け取った幹事を確かめて「〇〇円 受け取った」を押します。
5. 押し間違えたときは、直後に出る「取り消す」で元に戻せます。
6. 出欠が変わったときは、行の中の「請求額を直す」で金額を変えます。
7. 集金が終わったら「この期の記録を CSV で保存」で Excel 用のファイルを保存できます。

会計担当は「Google アカウントで入る（会計担当）」からサインインすることもできます。

## 初めて使うときの準備（会計担当が一度だけ）

### 1. Firebase のプロジェクトを作る

1. <https://console.firebase.google.com/> を開き、Google アカウントでサインインします。
2. 「プロジェクトを作成」を押し、名前を付けます。Google アナリティクスはオフで構いません。

### 2. ウェブアプリを登録して設定値を貼る

1. プロジェクトのトップで「ウェブ」（`</>` の印）を押してアプリを登録します。Firebase Hosting は使いません。
2. 表示された `firebaseConfig` の値を、このリポジトリの `firebase-config.js` に貼ります。
3. この値は公開されても問題ない設定値です。データはサインインとルールで守ります。

### 3. ログイン方法を有効にする

1. 左のメニューの「構築」→「Authentication」→「始める」を押します。
2. 「ログイン方法」で「Google」を有効にして保存します。
3. 同じ画面の「新しいプロバイダを追加」で「メール / パスワード」を有効にして保存します。「メールリンク」は使いません。

### 4. このページのアドレスを許可する

1. 「Authentication」→「設定」→「承認済みドメイン」を開きます。
2. 「ドメインの追加」で、このページのドメイン（`<GitHub のユーザー名>.github.io`）を追加します。

### 5. Firestore を作る

1. 「構築」→「Firestore Database」→「データベースの作成」を押します。
2. ロケーションは `asia-northeast1`（東京）を選びます。
3. 「本番環境モード」で開始します。

### 6. ルールを入れる

1. 「Firestore Database」→「ルール」を開きます。
2. 中身をすべて消して、このリポジトリの `firestore.rules` の内容を貼り、「公開」を押します。

### 7. 共通アカウントを作る

1. 「Authentication」→「ユーザー」→「ユーザーを追加」を押します。
2. メールアドレスに `firebase-config.js` の `sharedLoginEmail` と同じアドレスを入れます。メールは届かない、名前だけのアドレスです。
3. 幹事で共有するパスワードを決めて入れ、「ユーザーを追加」を押します。6 文字以上で、推測されにくいものにしてください。

### 8. 幹事の一覧を登録する

1. 「Firestore Database」→「データ」で「コレクションを開始」を押します。
2. コレクション ID を `access`、ドキュメント ID を `kanji` にします。
3. フィールド名 `emails`、型「array」で、次のアドレスを 1 件ずつ追加します。すべて小文字で入れてください。
   - 共通アカウントのアドレス（`sharedLoginEmail`）
   - Google でサインインする人の Google アカウントのアドレス

### 9. 新しいアカウントの登録を止める

1. 「Authentication」→「設定」→「ユーザー アクション」を開きます。
2. 「作成（登録）を有効にする」の印を外して保存します。
3. これで、ページからは新しいアカウントを作れなくなります。共通アカウントと、すでにサインインしたことのある Google アカウントはそのまま使えます。

### 10. 最初の名簿を取り込む

1. ページを開いて入ると「まだデータがありません」と出ます。
2. 名簿と請求額の JSON ファイルを選び、「取り込む」を押します。

## 共通パスワードを変えるとき（幹事の交代など）

1. 「Authentication」→「ユーザー」で共通アカウントの行の「︙」から「アカウントを削除」を押します。
2. 手順 7 と同じアドレスで、新しいパスワードを付けて作り直します。
3. 幹事の一覧（`emails`）はアドレスで判断するので、直す必要はありません。
4. 各スマホでは、次に開いたときに新しいパスワードの入力を求められます。

## Google でサインインする人を追加・削除するとき

1. 「Firestore Database」→「データ」→ `access` → `kanji` の `emails` を編集します。
2. 新しい人が初めて Google でサインインするときだけ、手順 9 の「作成（登録）を有効にする」を一時的に戻します。サインインできたら、また印を外します。

## 費用

Firebase の無料プラン（Spark）の範囲で使えます。クレジットカードの登録は要りません。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面と見た目 |
| `app.js` | 記録・集計・CSV などの動き |
| `firebase.js` | Firebase とのつなぎ |
| `firebase-config.js` | Firebase の設定値と共通アカウントのアドレス |
| `firestore.rules` | 読み書きできる人を決めるルール |
