# お茶会 会費集金

手渡しで受け取った会費・宴会費を、その場でスマホから記録するウェブアプリです。

- 画面は GitHub Pages から配信します。
- 記録は Firebase の Firestore に保存します。
- 読み書きできるのは、幹事の一覧に登録した Google アカウントだけです。
- 名簿や金額はこのリポジトリには入っていません。最初の名簿は、会計担当が JSON ファイルから取り込みます。

## 使い方

1. ページを開き、幹事の Google アカウントでサインインします。
2. 上のタブで期を選びます。
3. 部員の行をタップし、受け取った幹事を選んで「〇〇円 受け取った」を押します。
4. 押し間違えたときは、直後に出る「取り消す」で元に戻せます。
5. 出欠が変わったときは、行の中の「請求額を直す」で金額を変えます。
6. 集金が終わったら「この期の記録を CSV で保存」で Excel 用のファイルを保存できます。

## 初めて使うときの準備（会計担当が一度だけ）

### 1. Firebase のプロジェクトを作る

1. <https://console.firebase.google.com/> を開き、Google アカウントでサインインします。
2. 「プロジェクトを作成」を押し、名前を付けます。Google アナリティクスはオフで構いません。

### 2. ウェブアプリを登録して設定値を貼る

1. プロジェクトのトップで「ウェブ」（`</>` の印）を押してアプリを登録します。Firebase Hosting は使いません。
2. 表示された `firebaseConfig` の値を、このリポジトリの `firebase-config.js` に貼ります。
3. この値は公開されても問題ない設定値です。データはサインインとルールで守ります。

### 3. Google でのサインインを有効にする

1. 左のメニューの「構築」→「Authentication」→「始める」を押します。
2. 「ログイン方法」で「Google」を選び、有効にして保存します。

### 4. このページのアドレスを許可する

1. 「Authentication」→「設定」→「承認済みドメイン」を開きます。
2. 「ドメインの追加」で、このページのドメイン（`<GitHub のユーザー名>.github.io`）を追加します。

### 5. Firestore を作る

1. 「構築」→「Firestore Database」→「データベースの作成」を押します。
2. ロケーションは `asia-northeast1`（東京）を選びます。
3. 「本番環境モード」で開始します。

### 6. ルールを入れる

1. 「Firestore Database」→「ルール」を開きます。
2. 中身をすべて消して、このリポジトリの `firestore.rules` の内容を貼り、「公開」を押します。

### 7. 幹事の一覧を登録する

1. 「Firestore Database」→「データ」で「コレクションを開始」を押します。
2. コレクション ID を `access`、ドキュメント ID を `kanji` にします。
3. フィールド名 `emails`、型「array」で、幹事の Google アカウントのメールアドレスを 1 件ずつ追加します。すべて小文字で入れてください。

### 8. 最初の名簿を取り込む

1. ページを開いてサインインすると「まだデータがありません」と出ます。
2. 名簿と請求額の JSON ファイルを選び、「取り込む」を押します。

## 幹事を追加・削除するとき

Firebase コンソールの「Firestore Database」→「データ」→ `access` → `kanji` の `emails` を編集します。アプリの画面からは変えられません。

## 費用

Firebase の無料プラン（Spark）の範囲で使えます。クレジットカードの登録は要りません。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面と見た目 |
| `app.js` | 記録・集計・CSV などの動き |
| `firebase.js` | Firebase とのつなぎ |
| `firebase-config.js` | Firebase の設定値 |
| `firestore.rules` | 読み書きできる人を決めるルール |
